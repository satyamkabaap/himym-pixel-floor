# The Story

It started as a broken Python script with trailing spaces and a leaked API key.
Over one Saturday it became:

- A multi-agent harness where Ted drafts, Marshall reviews, and Lily signs off
- A sitcom with scripted episodes (Slapsgiving, Blue French Horn, The Playbook)
- A platform where you hire guest stars by dropping a JSON file
- A memory palace where the gang remembers what matters
- A coworker simulator with audit trails inspired by CopilotKit's OpenBot
- A pixel-art floor with day/night cycles, weather, and ambient life
- One exe, zero telemetry, zero dependencies beyond stdlib + requests

Built by a human and two AI agents (Hermes codes, a reviewer reviews).
The gang reviews the gang. The pipeline ships the pipeline.
