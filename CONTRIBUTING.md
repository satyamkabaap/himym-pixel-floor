# Contributing to himym-pixel-floor

Thank you for considering contributing to himym-pixel-floor! Please read this document to understand how you can help.

## How Can I Contribute?

### Reporting Bugs

Before submitting a bug report, please check if it has already been reported by searching the [Issues](../../issues).

If you're unable to find an open issue addressing the problem, [open a new issue](../../issues/new/choose). Be sure to include:

- A clear and descriptive title.
- A step-by-step description of how to reproduce the bug.
- Any relevant screenshots or screen recordings.
- Your environment (OS, Python version, etc.).

### Suggesting Enhancements

Enhancement suggestions are tracked as [Issues](../../issues). When suggesting an enhancement, please include:

- A clear and descriptive title.
- A detailed description of the proposed enhancement.
- Any potential drawbacks or considerations.

### Your First Code Contribution

If you're unsure where to start, look for issues labeled [`good first issue`](../../issues?q=is%3Aopen+is%3Aissue+label%3A%22good+first+issue%22).

### Pull Requests

1. Fork the repository and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. Ensure your code passes existing tests.
4. Make sure your code lints (if linting is configured).
5. Issue that pull request!

## Style Guidelines

### Git Commit Messages

- Use the present tense ("Add feature" not "Added feature").
- Use the imperative mood ("Move cursor to..." not "Moves cursor to...").
- Limit the first line to 72 characters or less.
- Reference issues and pull requests liberally after the first line.

### Python Code Style

- Follow [PEP 8](https://www.python.org/dev/peps/pep-0008/).
- Use 4 spaces per indentation level.
- Limit lines to 79 characters.

## Additional Notes

### Issue and Pull Request Labels

This project uses labels to organize work. Examples:

- `bug`: Something isn't working.
- `enhancement`: A new feature or improvement.
- `documentation`: Improvements or additions to documentation.
- `good first issue`: Great for newcomers.
- `help wanted`: Extra attention is needed.

Thank you again for your contribution!
